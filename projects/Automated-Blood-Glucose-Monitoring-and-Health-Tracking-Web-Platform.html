Automated Blood Glucose Monitoring and Health Tracking Web Platform

A comprehensive web-based application designed to monitor and store user blood glucose data, offering real-time AI-driven insights and historical health analysis.

Project Details

Project Overview

  • The objective was to create a robust web application for users to input and monitor their daily blood glucose levels. The platform serves as a digital health assistant that leverages AI for data interpretation.

Core Functionality

  • Data Acquisition: Users can upload or manually enter glucose readings, which are then processed via an intelligent backend.
  • AI Integration: The system uses advanced AI processing to analyze data trends and provide immediate health metrics.
  • User Features: Includes a comprehensive health history tab and a secure profile management system with password recovery and administrative support.

Technical Architecture

  • Frontend: Developed using HTML5, CSS3, and JavaScript.
  • IDE: Engineered using the Cursor code editor.
  • Backend: Managed via Node.js/En-8n integration with various workflow automations.
  • Database: Secure, centralized database architecture to store and retrieve health records effectively.
