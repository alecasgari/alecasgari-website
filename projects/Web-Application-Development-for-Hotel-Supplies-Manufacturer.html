Web Application Development for Hotel Supplies Manufacturer

I designed and developed a frontend and backend web application for Leart to showcase hotel supplies and manage generated leads with social media integration.

Youssef Sandalwala Leart
Date
Duration 1 year

Project Details

Overview

I designed and developed a complete web application featuring both frontend and backend architecture for Leart, a company specializing in the manufacture of hotel supplies such as bathroom sets, control holders, and trays. The project provided the company with a dedicated digital platform to showcase its product catalog, manage incoming leads, and integrate its online presence with social media channels.

The Problem

Leart operated in the hotel supplies manufacturing sector without a centralized digital platform. The company lacked an organized system to capture and manage generated leads, and it had no online showcase to display its product range to potential customers.

My Approach

My approach focused on building a comprehensive web application that addressed both the customer-facing and administrative requirements of the business. I structured the project to include both frontend and backend components, ensuring that product displays and lead data flow together smoothly. I also established integration points with the company's social media channels to help capture inquiries and connect them to the core application.

The Solution

The delivered web application serves as a central hub for Leart's digital operations. Leads and product inquiries generated through the company's online channels and social media are routed directly into the platform, where they can be systematically managed. Simultaneously, the application provides a structured product showcase where customers can explore the manufacturer's catalog of bathroom sets, trays, and related items.

Technical Stack

To build this solution, I selected a reliable set of web development and design technologies suited for creating a full-stack application and supporting visual assets.

  • HTML5: I used it to structure the core content and layout of the web application pages.
  • CSS: It provided the styling rules to ensure a clean and professional presentation for the product showcase.
  • React: I used this frontend library to build interactive user interfaces for the web application.
  • JavaScript: It powered the interactive behaviors and client-side logic across the application.
  • Node.js: I used it to build the backend environment supporting the application's server-side operations and data handling.
  • Photoshop: It assisted in editing and preparing visual assets for the project.
  • Illustrator: I used it to create vector graphics and brand visual elements.
  • Canva: It supported rapid design layout creation for various project materials.
  • Cursor: I utilized it as an AI-powered code editor to assist with the development workflow.

Results & Impact

The completed web application successfully equipped Leart with the foundational digital infrastructure it previously lacked. The platform supports structured product display and organized lead management in one environment. Following the implementation and deployment of the project, the client achieved a 30 percent increase in sales.

Key Takeaways

  • Full-stack implementation: I built a complete web application combining both frontend interfaces and backend server logic.
  • Centralized lead management: The application provides a dedicated space to organize and track generated leads.
  • Product visibility: The digital showcase gives customers a clear way to explore manufactured hotel supplies.
  • Social media connectivity: Integrating the platform with social media channels helps bridge the gap between initial inquiries and lead management.
