Automated Instagram and YouTube Video Syndication System

I built an automated pipeline that fetches social media content, processes it, and publishes it directly to a static website for Dr. Giv Sharifi. This removes the need for manual content updates.

Date June 29, 2026
Duration 4 weeks

Project Details

Overview

I developed an automated system for Dr. Giv Sharifi to synchronize his social media activity with his professional website. The primary goal was to ensure that any video he posts on Instagram or YouTube is automatically mirrored to his site without manual intervention.

This project was designed to save the team time and keep the website updated with fresh, dynamic content. By automating this, I allowed the team to focus on content creation rather than administrative web management.

The Problem

Before this system was implemented, every video had to be downloaded, processed, and uploaded to the website manually. This process was time-consuming, prone to human error, and inconsistent.

It required constant manual effort, including logging into multiple dashboards, managing file metadata, and updating the site via a CMS. This was inefficient and didn't support the fast-paced nature of modern social media content.

My Approach

I focused on building a robust, event-driven architecture that responds to Telegram signals. I mapped out the entire lifecycle of a video, from the moment of notification to the final static site deployment.

My priority was reliability. I designed the architecture to handle failures gracefully, ensuring that data is never lost during the transmission between social platforms and the website.

The Solution

I implemented a Telegram-based bot that acts as the command center for the system. Once a signal is received, the bot triggers a pipeline that fetches the video, extracts the necessary metadata, and formats it for the web.

I utilized Gemini to generate descriptive titles and summaries for each video, which helps with site accessibility and searchability. Finally, the system updates the site content and triggers a deployment via GitHub Pages to ensure the site stays performant and secure.

Technical Stack

  • n8n for workflow orchestration and logic.
  • VPS hosted environment for background processing.
  • Gemini AI for automated description generation.
  • CloudFlare R2 for secure, scalable file storage.
  • Python and JSON for data processing and integration.

Results & Impact

The primary outcome was a complete removal of manual content management tasks. The team no longer needs to touch the website to share new videos, as the content now appears live shortly after the initial post.

By leveraging an automated pipeline, the website is always up to date, improving both user experience and SEO. I successfully transformed a manual, repetitive chore into a hands-off, efficient automated service.

Key Takeaways

  • Automation should focus on eliminating repetitive manual tasks that consume valuable time.
  • Decentralizing the logic from the web server ensures better security and performance.
  • Using a robust CI/CD approach for static sites results in faster, more stable web content delivery.
